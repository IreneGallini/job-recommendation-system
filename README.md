# job-recommendation-system

Goal: internship postings for summer 2027

Locations: US, Italy, EU, UK, Singapore

Work style: both in person and remote


Classification:
- big tech
- startup
- specific industry (for example pharma, biotech)

Current plan:
- email notifications every 24 hours highlighting high preference roles
- all jobs sent to discord server every 24 hours

Storage
- initially cloud free tier 
- future: Raspberry Pi locally Postgres

Sources:
- boards:
    - SimplifyJobs
    - Linkedin
    - Handshake
- specific company websites:
    - Google
    - Meta
    - Apple
    - NVIDIA

Position key words:
- software engineer
- data science
- data analyst
- data engineer
- ml engineer
- ai engineer

Features: 
- Scraping every 6 hours
- store jobs + display on .md file in table
- 24 hour email notifications
- suggest people to network with 
    - based on common school, interest, position, etc 
    - find contact info
    - summary and suggested questions for coffee chat
    - write reach out message
